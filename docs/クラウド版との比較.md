# クラウド版にしたらどうなるか（PC常駐版との比較）

いまは **社長PCに常駐する版** で作っている。もし **クラウド版**（Vercel などに置いて、どの端末からもURLで開く形）にすると、どう変わるかを並べる。

| 見るところ | 今：社長PCに常駐 | もし：クラウド版 |
|---|---|---|
| **AIの料金** | 社長の**月額クロード（`claude -p`）が使える**＝ふだん¥0。上限超過時だけ従量課金 | 月額クロードは**使えない**。最初から**従量課金API**だけ（claudeのサブスクはアプリから呼べない） |
| **記憶の置き場** | **社長のPCの中だけ**。外に出ない | **クラウド（Supabase等）に出る**。社長のPCの外にデータが置かれる |
| **井手さんが中身を読めるか** | **読めない**（PCの中にある。物理的に無理） | 仕組み上は**読めてしまう**。読めないようにするには暗号化などの作り込みが要る |
| **PCの電源** | **点いている時だけ**使える | PCに関係なく**いつでも**使える |
| **スマホから** | Tailscale でPCにつなぐ（PCが起きている時） | **どこからでも**URLで開ける |
| **初回の手間** | クロード デスクトップアプリに指示書を貼る＋Tailscale | 社長がアカウント（Anthropic等）を作る＋カード登録＋井手さんを招待 |
| **この先の更新** | GitHub→PCが自動取得 | GitHub→自動で反映 |
| **月々の固定費** | ¥0（上限超過時のみ従量） | 置き場の料金が乗ることがある＋AIは常に従量課金 |

## どちらが向くか
- **今の常駐版が向く**：社長の月額クロードを活かしたい／記憶を外に出したくない／固定費を増やしたくない。**井手さんが選んだのはこちら。**
- **クラウド版が向く**：社長がPCをあまり点けない／複数端末からいつでも使いたい。ただし**AIは常に従量課金**になり、**記憶が外に出る**ので、プライバシーは作り込みが必要。

## まとめ
クラウド版は「どこからでも・PCに縛られない」が強み。
その代わり **①月額クロードが使えず従量課金だけになる ②記憶が社長のPCの外に出る** の2つが引っかかる。
「月額クロードで動かす・記憶はPCの中」を優先したので、**常駐版**で進めている。
もし後から「どこからでも開きたい」が強くなれば、同じ本体をクラウド版にも載せ替えられる作りにしてある（画面と記憶の置き場を差し替えるだけ）。
