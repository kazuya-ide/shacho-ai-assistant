# 記憶のバックアップ（社長の会話・人格を守る）

秘書の記憶（人格・覚えごと・会話）は、**社長のPCの中だけ**にあります。これは安心な反面、
**PCが壊れたり無くしたりすると、記憶も全部消えます**。それを防ぐのがバックアップです。

## 大事な考え方
- バックアップは **暗号化**して作ります。鍵が無いと中身は読めません（**井手さんにも読めません**）。
- だから、暗号化したバックアップは **クラウド（OneDrive / Googleドライブ）や外付けに置いても安全**です。
- 鍵ファイル `config/backup.key` が復元のかなめ。**無くすと二度と戻せません**。

## バックアップの作り方
退避先フォルダを指定して実行します（クラウド同期フォルダか外付けがおすすめ）。
```
npm run backup -- "D:\秘書バックアップ"
```
または
```
node tools/backup.mjs "C:\Users\（社長）\OneDrive\秘書バックアップ"
```
- 初回だけ、鍵 `config/backup.key` が自動で作られます。
  **この鍵を、USBメモリなど別の場所にもコピーして保管してください**（PCと一緒に壊れないように）。
- 実行すると `秘書_記憶バックアップ_2026-11-09.enc` のような**暗号ファイル**ができます。

## 自動で毎日とるには
Windowsの「タスクスケジューラ」で、1日1回 `node tools/backup.mjs "退避先"` を動かすように登録します（井手さんが設定）。

## 元に戻す（復元）
新しいPCや、記憶が消えたときに戻します。`config/backup.key`（保管しておいた鍵）を `config/` に置いてから：
```
npm run restore -- "秘書_記憶バックアップ_2026-11-09.enc"
```
鍵が正しければ、人格・記憶が元どおりになります。

## まとめ（社長にお伝えすること）
- 記憶は社長のPCの中だけ。**だから時々バックアップを取る**（自動にもできます）。
- バックアップは暗号化されていて、**井手さんにも中身は見えません**。
- **鍵（backup.key）だけは、別の場所にも保管**してください。これが唯一の注意点です。
