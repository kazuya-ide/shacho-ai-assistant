# 記憶の入れ方（memory/notes）

このフォルダに **`.md`（文章ファイル）を置くと、それがアシスタントの「記憶」になります。**
1つのことを1枚にすると、あとで直しやすいです。何枚でも足せます。

## 例
- `思想.md` … 堀内さんの考え方・大事にしていること
- `好み.md` … 好きなもの・苦手なもの
- `会社.md` … 会社や仕事の前提
- `人間関係.md` … よく出てくる人

## 書き方
ふつうの文章で大丈夫です。見出し（`#`）で区切ると読みやすくなります。
ここに置いたものは **社長のPCの中だけ** にあり、クラウドにも井手さんのところにも出ません。

## クロードの過去の会話を記憶にしたいとき
堀内さんが claude.ai で「会話の書き出し」や「自己紹介のまとめ」を作れます。
その文章をこのフォルダに `.md` で置けば、これまでのクロードの記憶と同じように読み込めます。
（この書き出しは堀内さん本人からしか出せないので、堀内さんにお願いする項目です。）
